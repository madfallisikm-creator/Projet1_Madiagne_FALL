# Projet 1 — Analyse des journaux d'un pare-feu

**Auteur : Madiagne FALL**

Analyse d'une semaine de connexions d'un pare-feu (PC, serveurs, objets IoT) :
nettoyage des données, calcul de 5 indicateurs, figures et rapport de sécurité.

## Lancer le projet

Le script lit `data/logs_reseau.csv`, écrit `resultats.json` et enregistre les graphiques dans `figures/`.

## Contenu

- `analyse.py` : nettoyage, calculs, figures
- `resultats.json` : résultats générés
- `rapport.md` : observations, comportements suspects, recommandations
- `figures/` : graphiques PNG
